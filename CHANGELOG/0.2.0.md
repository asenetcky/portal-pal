# 0.2.0

## Features

- **ETL workspace** — new `apps/etl/` monorepo workspace that scrapes dataset metadata from open data portals (Socrata) and upserts it into a Supabase `raw_metadata` staging table. Entry point: `apps/etl/src/etl/main.py`.
- **Scheduled metadata extraction** — `metadata-extract` GitHub Actions workflow runs nightly at midnight UTC (`cron: '0 0 * * *'`), fetching metadata from `data.ct.gov` and writing it to Supabase. Also supports manual `workflow_dispatch` triggers.
- **Dependabot uv support** — added the `uv` ecosystem to Dependabot config so ETL and backend Python dependencies receive automated update PRs.

## Fixes

- Added dummy Supabase env vars to CI so pydantic-settings validation passes in test runs.
